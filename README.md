# Лабораторная работа №4

**Задача**: написать алгоритмический мини-пакет

**Реализовано**:

- Наибольший общий делителей двух целых чисел, итеративно и рекурсивно (`gcd.py`). По умолчанию рекурсия в Python ограничена 1000 вызовами.
- Квадратичная сортировка insertion sort (O(n^2)) с параметрами key и reverse (`sort.py`). Сортирует исходный список.
- Эффективная сортировка quick sort (O(n*log n)) с параметрами key и reverse (`sort.py`). Сортирует исходный список.
- Очередь на list (`queue.py`)
- Генератор наборов данных (`data_generator.py`) различных типов (`str`, `int`, `float`) и видов: случайный, отсортированный, обратный, почти отсортированный, с большим количеством дубликатов, а также поддержкой `seed`.
- Бенчмарк для сортировок (`benchmark.py`) с поддержкой различных размеров входных данных и пользовательских функций сортировки, а также формированием markdown-таблицы. Подробнее см. ниже
- Анализ трёх сортировок: реализованных insertion sort и quick sort, а также встроенной sort для сравнения (`insertion.md`, `quick.md` и `python.md` соответственно)

**Бенчмарк**:

В связи с использованием SIGALRM в целях предотвращения чересчур долгого исполнения функций сортировки (по умолчанию время ограничено 30 секундами), **не поддерживается работа на Windows**. Вы можете установить докер-контейнер с benchmark (там так же лежат `sort.py` и `data_generator.py` и установлен vim. Dockerfile для образа лежит в репозитории, при необходимости можете изменить)
```bash
docker pull ghcr.io/regmain/py_lab04:latest

docker run -it ghcr.io/regmain/py_lab04:latest
```
Вы окажетесь в директории /app, где сможете запустить benchmark в демонстрационном режиме (или изменить) при помощи `python src/py_lab04/benchmark.py`. По умолчанию программа создаёт три markdown-таблицы, лежащие в репозитории. Вы можете изменить: 
```python
...
if __name__=="__main__":
  benchmark = SortBenchmark()
  benchmark.test(my_sort)
  benchmark.make_report("my_sort.md")
```

**Выводы**

- Insertion sort на входных данных более 10'000 нежизнеспособен (соответствует асимптотике)
- Quick sort ведёт себя соответственно асимптотике (изменение квазилинейное, около 10-20 раз каждый раз, что корректно), но намного медленнее встроенного `sort` (вероятно из-за того, что он реализован на C)
